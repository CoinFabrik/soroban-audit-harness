# Knowledge Pack Provenance

The default H2 knowledge pack contains CoinFabrik-authored security-review procedures synthesized from public Soroban audit reports, published security research, and CoinFabrik's security experience.

The packets do not reproduce source reports or include project-specific findings, vulnerable code, commits, source excerpts, or answer keys. The reports and the private normalized vulnerability dataset used during the research project are not distributed with this repository.

This `default-v1` directory preserves the five-packet knowledge input used by H2 in the reported benchmark. Future packet revisions must use a new versioned directory so that historical runs remain reproducible.

The packets provide investigation procedures, not vulnerability conclusions. Every candidate must be established from the repository being analyzed and independently validated before disclosure.
